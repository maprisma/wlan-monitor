# Interface translations

The eight base catalogs were copied from Omarchy WLAN Monitor's `I18n.js`.
Its symbolic keys are replaced with the exact English strings. English plural
forms become individual English keys; `plurals.json` retains every original
plural form, including Polish one/few/many. The original repository is read only.
Each base catalog contains 221 English keys. Port-specific text is in
`extra/<code>.json`: 14 additional keys per language, with no base overrides.

All assets are compiled with `include_str!`; there are no runtime catalog files
or downloads. After editing catalogs, run `python3 tools/gen-translations`.
To refresh from an original checkout (read only):

```sh
python3 tools/gen-translations --import-original /path/to/omarchy-wlan-monitor/I18n.js
```

`tr("English")` translates a literal, and `trf("English {0}", &[value])`
substitutes values without translating them or interpreting their braces.
Untranslated keys stay English. `cargo test --offline` checks source keys,
placeholder coverage, bundled catalog freshness, desktop localization,
system locale precedence, settings persistence, fallback and Polish plurals.

The Language button is in the applet popup/window footer; the KDE tray has a
Language submenu. Both offer System (language name), then the eight native
language names. The setting is `auto` or a code in
`$XDG_CONFIG_HOME/ubruckhaus-wlan-monitor/maprisma-settings.json`
(`~/.config` by default). LC_ALL, LC_MESSAGES and LANG are checked in order,
using the first nonempty value; unknown locales, C and POSIX resolve to English.
UI choices update immediately. Other running instances pick up the file on
their next normal refresh. The Rust UI sends the existing `lang` command to
the unchanged Python collector, which already supplies translated notifications.
The helper matches the original byte for byte, including its WLAN Monitor
notification application name.

Device names, models, addresses, interface names, commands, units and platform
brands are data, so they remain unchanged. Developer logs and installer console
instructions remain English. Desktop names and comments are localized,
including the window and tray desktop entries generated by the installer.
